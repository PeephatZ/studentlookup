# Student Lookup App

ระบบค้นหาข้อมูลนักเรียน โรงเรียนเขมราฐพิทยาคม ปีการศึกษา 2568

## Features
- ค้นหานักเรียนด้วยรหัสประจำตัว
- แสดงข้อมูลชั้นเรียนและห้องเรียน
- บันทึกชื่อแอคเค้าของนักเรียน
- เชื่อมต่อกับ Google Sheets

## Setup
1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the app:
```bash
streamlit run app.py
```

## Deploy on Streamlit Cloud
1. Fork this repository
2. Connect to Streamlit Cloud
3. Set up secrets for Google Sheets API
4. Deploy!
